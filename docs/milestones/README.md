# Milestones

This directory breaks the next phase of the product into implementation-sized milestones.

Execution order:

1. `M1-analysis-persistence.md`
2. `M2-frontend-read-apis.md`
3. `M3-portfolio-insights.md`
4. `M4-user-management-foundation.md`

Working rule:

- implement one milestone at a time
- complete schema, API, and tests for that milestone before moving on
- keep later milestone assumptions out of earlier code unless explicitly needed

Current recommendation:

- start with `M1-analysis-persistence.md`
- do not start frontend auth before `M1` and `M2` are stable
